# Governance and Reproducibility

This folder captures the controls that make the Validation stage trustworthy and reviewable.

## Minimum controls
- fixed configs for reported runs
- dataset provenance notes
- versioned code commits for all reported results
- logged seeds and environment details
- explicit release criteria for claiming success
- known limitations section that cannot be removed from reports

## Goal
Make it possible for a reviewer to reproduce DIGIT claims and understand what controls were in place during testing.
