# Datasets for DIGIT Validation

This folder defines the benchmark suite used by the Validation stage.

## Selected datasets
- NIST Genomics PPFL competitor pack — privacy stress-testing benchmark
- PRISM — drug-discovery utility benchmark
- TCGA — omics realism benchmark
- MIMIC-IV demo — healthcare-style sanity-check benchmark before full-access clinical datasets

Each dataset file should define:
- motivation for inclusion
- access method
- task candidates
- privacy unit
- preprocessing constraints
- allowed splits
- baseline tasks
