# Stress Plan

## Query stress
Measure attack and utility behavior as the number of allowed queries increases.

## Interface stress
Vary the number of discrete states or buckets exposed by the bottleneck and measure leakage / utility changes.

## Data stress
Test DIGIT on harder splits, noisier inputs, and distribution-shift variants where feasible.

## Reproducibility stress
Repeat all key experiments across multiple seeds and confirm ranking stability.
